## Запуск

Нужен Python 3.10 или новее с Tkinter. Сторонние пакеты не требуются.

```console
python main.py
python -m unittest -v
```

В Windows можно использовать `py -3`. Каталог создаёт `lab5.sqlite3` в
текущей папке. Для отдельной базы запустите `python main.py --db demo.sqlite3`.

## Демонстрация

1. В калькуляторе введите `0,1` и `0,2`, выберите `+` и нажмите «Вычислить».
   Результат равен `0.3`. При делении на ноль появится сообщение об ошибке.
2. Переключите вкладки. На цветной панели нажмите «Сменить цвет».
3. В кликере нажмите «Нажать» несколько раз и сбросьте счётчик.
4. В каталоге добавьте «Учебник Python». Закройте и откройте программу,
   чтобы увидеть сохранённую запись. Выберите её и нажмите «Удалить выбранную».

`main.py` связывает виджеты с обработчиками, `calculator.py` выполняет
операции через `Decimal`, `catalog.py` выполняет параметризованные запросы SQLite.
